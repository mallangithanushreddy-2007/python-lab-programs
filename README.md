# Python Lab Programs

A repository containing Python laboratory practical programs, exercises, and mini projects.

## Table of Programs

| # | Program File | Description |
|---|-------------|-------------|
| 1 | `01_student_report.py` | Calculates total and average marks and prints a formatted student report card. |
| 2 | `02_electricity_bill_generator.py` | Computes consumed units, energy charges, 5% electricity duty, fixed meter charges, and net bill. |
| 3 | `03_otp_generator.py` | Generates a 4-digit or 6-digit one-time password (OTP) using Python's `random` module. |
| 4 | `04_fibonacci_series.py` | Computes and displays the first `n` numbers in the Fibonacci sequence. |
| 5 | `05_contact_book.py` | Console-based interactive menu to Add, View, Search, Delete, and Update contacts. |
| 6 | `06_student_grading_system.py` | Records student marks in a dictionary and assigns letter grades (A, B, C, D, E, Fail). |
| 7 | `07_character_frequency.py` | Counts the frequency of each character in an input string using a dictionary. |
| 8 | `08_attendance_report.py` | Records attendance (Present/Absent) and computes total counts and attendance percentage. |
| 9 | `09_log_file_error_counter.py` | Reads lines from `log.txt`, counts lines containing the keyword `"Error"`, and handles missing file errors. |
| 10 | `10_student_data_manager.py` | Menu-driven file manager storing and retrieving student records from `students.txt`. |
| 11 | `11_payroll_csv_generator.py` | Collects employee details and generates a payroll calculation spreadsheet (`payroll.csv`). |
| 12 | `12_log_json_analyzer.py` | Parses and summarizes log levels (`INFO`, `WARNING`, `ERROR`) from a structured `logs.json` file. |
| 13 | `13_dice_simulator.py` | Object-oriented dice simulator with repeat play options using `random`. |
| 14 | `14_sales_dashboard.py` | Data analytics dashboard loading retail sales data (`sales.csv`) and visualizing trends using pandas & matplotlib. |

---

## Prerequisites
For programs 1 to 13, standard Python 3 is sufficient.
For `14_sales_dashboard.py`, install the required data analysis libraries:
```bash
pip install pandas matplotlib
```

---

## How to Run

### In VS Code or Terminal
1. Open the project folder in terminal or VS Code:
   ```bash
   cd python-lab-programs
   ```
2. Run any program using Python 3:
   ```bash
   python 01_student_report.py
   python 02_electricity_bill_generator.py
   python 03_otp_generator.py
   python 04_fibonacci_series.py
   python 05_contact_book.py
   python 06_student_grading_system.py
   python 07_character_frequency.py
   python 08_attendance_report.py
   python 09_log_file_error_counter.py
   python 10_student_data_manager.py
   python 11_payroll_csv_generator.py
   python 12_log_json_analyzer.py
   python 13_dice_simulator.py
   python 14_sales_dashboard.py
   ```
